# Album Planner

Plan photo album pages on your phone and get the prints ready. Works offline once opened.

- **Pages:** XL (one big photo) or 2 L plus 0–3 extras, each extra a small S photo or a note (ticket, boarding pass…).
- **Save prints:** one zip with a folder per size: original XL and L photos, and S photos combined three at a time into 18×8 cm strips.
- **Album plan (PDF):** which photo goes where on every page, including which strip each S photo is on.

Photos never leave the phone; the website only delivers the app.

## Install on iPhone
Open the site in Safari → Share → Add to Home Screen → open it once while online.

## Updating
Bump `CACHE` in `sw.js` with every change so installed copies pick up the new version.
